## ✨ Features

- 🌗 Auto light/dark theme — follows your system preference
- ⚡ Zero dependencies, zero build tools — pure HTML/CSS/JS
- ♿ Accessible — skip links, ARIA labels, full keyboard nav
- 📱 Responsive, fast, and lightweight
- 🔒 Hardened with a strict Content-Security-Policy

## 📂 Structure

```
├── index.html      → all the content
├── css/             → styles (tokens, layout, components)
├── js/main.js       → theme, animations, nav
└── assets/          → résumé, images
```

## 🚀 Run it locally

```bash
git clone https://github.com/Sidharthkris/sidharthkris.github.io.git
cd sidharthkris.github.io
python3 -m http.server 8000
```

Open `localhost:8000` — that's it.
